# BLE Player

VORZE U.F.O. SA をブラウザから制御するプレイヤーアプリ。  
動画・音声ファイルの再生に合わせて、CSVで記述したタイミングでデバイスを動作させます。

---

## 動作環境

| 環境 | 対応状況 |
|------|----------|
| PC（Chrome / Edge） | ✅ フル対応 |
| Android（Chrome） | ✅ 対応（ファイル操作除く） |
| iOS | ❌ Web Bluetooth API 非対応 |

**HTTPS 必須です。** ローカルの `file://` では Web Bluetooth API が動作しません。  
GitHub Pages などの HTTPS 環境で使用してください。

## フォルダ構成

フォルダをそのままアプリに読み込ませます。構成は以下を想定しています。

```
作品フォルダ/
├── track01.mp4       # 動画または音声ファイル
├── track01.csv       # タイミングデータ（省略可）
├── cover.jpg         # サムネイル（音声再生時に表示）
└── subFolder/        # サブフォルダ（任意の深さ）
      ├── track02.mp4
      └── track02.csv
```

**トラック名は作品フォルダ全体で重複させないでください。** このアプリはトラックをファイル名で管理するため、サブフォルダをまたいだ同名（上の例で `track01.mp4` が2つある状態）は区別できず、後から読み込んだ方が上書きされます。同じフォルダ内での拡張子違い（`track01.mp4` と `track01.wav`）も含めて、今回の読み込みで重複を検出したらアラートを表示します。以前にライブラリ登録済みの作品との同名は検出できません（アプリ側では区別できないため、名前で管理している以上は避けてください）。

### CSVとトラックの紐づけ

| 状況 | 動作 |
|------|------|
| 同じフォルダ内にトラックと**同名**のCSVがある | そのCSVを割り当てる（最優先） |
| 残りのトラック数と未使用CSV数が同数 | 残りだけをファイル名（自然順）の順に対応付ける |
| 上記に当てはまらない | **未割当**（CSVを1枚だけ置いても全トラックには適用しない） |
| CSVが0個 | 全トラック未割当 |

同名の対応と自然順（`track2` は `track10` より前）は**フォルダ内**の話です。サブフォルダをまたいだ同名CSVは対応しません（各フォルダにそのトラックのCSVを置いてください）。サブフォルダ間の表示順はスキャン順のままです。

トラックが1本・CSVが1枚だけの場合は、名前がちがっても対応します（1トラックに1枚は、そのトラック用と解釈できるため）。複数トラックに同じ動きをさせたい場合は、各トラックと同じ名前の CSV を置いてください。

## CSVフォーマット

```csv
time_ms,direction,strength
0,0,0
10000,1,50
20000,0,80
```

| カラム | 内容 |
|--------|------|
| `time_ms` | 再生開始からの経過時間（**ミリ秒**） |
| `direction` | 向き（`0` = 右、`1` = 左） |
| `strength` | 強さ（`0` 〜 `100`） |

`time_ms` は名称どおり **ミリ秒** です。上記の例は 10 秒目と 20 秒目に動作します。

### 既存 CSV（1/10秒形式）の移行

2026年11月より前は `time_ms` の値が **1/10秒（デシ秒）** でした。古い CSV はそのままだと動作が10倍早く始まります。

CSV編集画面のツールバーにある **「1/10秒→ms 変換」** を押すと、全行の時間値を100倍して ms に変換してから保存できます（Undo 可能）。1ファイルずつ変換してください。

## 使い方

### 1. 接続

アプリを開くと BLE 接続画面が表示されます。

1. **「UFO SA に接続する」** をタップ
2. ブラウザのデバイス選択ダイアログで **UFOSA** を選択
3. 接続成功後、メイン画面へ遷移

動作確認したい場合は **「接続せずに続ける（テスト用）」** でスキップできます。

CSV編集画面から戻ったときは接続画面は出ません。メイン画面のまま、上のドットが赤になって「編集画面から戻りました — 機器は切断中です」と出ます。接続は画面上部の **「UFO SA を再接続」** から行ってください（機器の再接続はブラウザの仕様上、必ずボタンの操作が必要です）。

### 2. フォルダを追加

- **PC**：メイン画面に遷移すると自動でフォルダ選択ダイアログが開きます
- **Android**：サイドバー下部の **「＋ フォルダを追加」** をタップ

初回追加時はメタデータ（作品名・サークル名・声優名・RJ番号）の入力画面が表示されます。スキップ可能です。

### 3. 再生

サイドバーから作品を選択 → トラックをタップで再生が始まります。  
CSVが紐づいていれば、再生位置に合わせてデバイスが自動で動作します。

**対応拡張子**

| 種類 | 拡張子 |
|------|--------|
| 動画 | `mp4` `m4v` `webm` `mov` `ogv` |
| 音声 | `mp3` `wav` `ogg` `m4a` `aac` `flac` `opus` |

再生中の動作は音声と動画の区別を拡張子から判定します（MIME情報がないファイルでも判定できるようにするため）。音声のときだけサムネイル画像を探します。画像は「トラックと同名の画像」→ `cover` `jacket` 等のよくある名前 → フォルダ内で最初に見つかった画像 の順に選ばれます。

#### 速度倍率

コントロールバーの **「速度倍率」** は、CSVの `strength` を実際の速度に変換する係数です。

```
実際の速度（0〜100） = strength × 速度倍率
```

既定は **50%** です（CSVに `strength=100` と書いてあっても、そのままでは速度50で動きます）。全力で動かすにはスライダーを100%にしてください。音量と速度倍率はこのブラウザに保存され、次回開いたときにも引き継がれます。

タイムライン右上のモード表示は **CSV モード** だけが動作します。「ランダム」「波形連動」は未実装です（選んでも動作は変わりません）。

### 4. CSV編集

トラックリスト右上の **「CSV編集」** から CSV 編集画面を開けます。

- タイムラインをタップしてマーカーを追加
- ミラーリング・繰り返し・フェードイン/アウトなどのツールが使えます
- **PC**：編集したCSVをファイルに直接上書き保存
- **Androidなど File System Access API が無い環境**：「保存」で編集内容は**このブラウザに保存**され、メイン画面に戻ると元のCSVより優先して反映されます。トラック一覧に「編集済」と表示されます。フォルダ側のファイルを差し替えたい場合は、トラックを右クリックして **「編集CSVの反映を取り消す」** を選んでください。そのブラウザセッション中は元のCSVに戻ります（ページを再読み込みすると元ファイルの参照は残らないので、未割当になります。その場合はフォルダをもう一度選択してください）。ダウンロードしての手動差し替え（「書出」ボタン）も引き続き使えます。
- **編集画面を開くとBLE接続は切れます**（ページを移動するため）。戻ったときは選んでいた作品とトラックを復元します。フォルダの中身も自動的に読み直しますが、**「＋ フォルダを追加」で選んだ作品のハンドルがブラウザに残っていて、読み書きの許可が続いている場合のみ**です。ドラッグ＆ドロップや Android の **「＋ フォルダを追加」** で追加した作品はハンドルが残らないので、自動の読み直しは起きません（ハンドルはブラウザの中にだけ保存され、ライブラリのJSON書き出しには含まれません）。それ以外の場合は **「フォルダを読み込む」** を押してください — 保存していたフォルダのハンドルが残っていればそこで許可を取り直してそのまま読みます（同じフォルダを選び直す必要はありません）。許可が切れていたときだけフォルダを選ぶ窓が開きます。読み込みが終われば編集しているトラックも開きます。読み直しで、同名トラックの警告や作品情報を入力する窓が復帰のたびに何度も出ることはありません。
  - **Android ではこの「フォルダを読み込む」ボタンは表示されません。** サイドバー下部の **「＋ フォルダを追加」** でフォルダを再選択してください。読み直した作品が選択中ならトラック一覧は正しく作り直されます（「未読込」のままで弾かれることはありません）が、編集していたトラックは勝手に開かないので一覧から選んでください。
  - 先に **「UFO SA を再接続」** を押しても「フォルダを読み込む」は消えません（接続とフォルダ読み込みは独立です）。
  - 機器との接続は自動では戻りません。画面上部の **「UFO SA を再接続」** を押して、ブラウザの一覧で UFOSA を選べば復旧します。

## BLE仕様

| 項目 | 内容 |
|------|------|
| デバイス名 | `UFOSA` |
| Service UUID | `40ee1111-63ec-4b7f-8ce7-712efd55b90e` |
| Characteristic UUID | `40ee2222-63ec-4b7f-8ce7-712efd55b90e` |
| コマンド形式 | `[0x02, 0x01, byte2]` |
| byte2 | MSB = 向き（0:右 / 1:左）、下位7bit = 速度（0〜100） |

動作の仕組み:

- 再生位置は rAF で照合します（`timeupdate` は約4Hzしか来ないため、1ms刻みで判定します）
- 同じフレーム内で複数行を通過したときは、**最後の1つだけ**送信します。機器には最新の状態だけが意味を持つためです
- 送信が詰まったときも、積み上げて古いコマンドを後から送ることはしません
- 切断に備えて5秒ごとに**直前に送ったコマンドを再送**します（接続維持のために毎回「停止」を送ると、動作中に止まってしまいます）。自動再接続に成功したあとは、切れる直前の状態をもう一度送ります
- 自動再接続に失敗したときは確認ダイアログが出ます。**「キャンセル」を選んでも問題ありません** — いつでも画面上部の **「UFO SA を再接続」** から、ブラウザのデバイス一覧で UFOSA を選んで復旧できます（Windowsでは150秒で切れることがあり、再生中の切断と復旧はよく起きます）

## ライブラリ管理

- 作品のメタデータは **localStorage** に保存されます（ブラウザを閉じても保持）
- 作品行・トラック行・サブフォルダ行を右クリックで、**ファイルとサブフォルダを実際にリネーム・削除**できます（PCのみ、ディスクに書き込みます。トラック行とサブフォルダ行には行末の ✎ / ✕ もあります）。作品行の右クリックメニューにある「フォルダをリネーム」「フォルダを削除」は、**その作品の親フォルダを一度選んでいるときだけ**効きます。File System Access APIには親フォルダを取り出す方法がないため、アプリが **「＋ フォルダを追加」** で選んだフォルダがそのまま作品フォルダになっている場合は、リネームは「できません」と言って止まり、削除はライブラリから外すだけになります（ディスク上のフォルダは残るので、名前を変えたり消したりするのはファイルマネージャーで行ってください）
- CSV編集画面から戻ったあとにリネーム・削除を使うには、その作品のフォルダを読み直してください（読み直していない場合は「フォルダが見つかりません」と出ます）
- サイドバー下部からライブラリを **JSON でエクスポート・インポート** できます。読み込みときは項目の形を検証し、欠けた項目は補った上で**現在のライブラリと統合**します（同じフォルダ名の作品だけ上書き）
- 機種変更やブラウザ移行の際はエクスポートしておくことを推奨します

## 技術スタック

| 技術 | 用途 |
|------|------|
| Web Bluetooth API | UFO SA との BLE 通信 |
| File System Access API | PC でのファイル読み書き |
| IndexedDB | CSV 編集画面へのファイル受け渡し、作品フォルダのハンドル保持（編集画面から戻ったときの再読み込み用。このブラウザの中にのみ保存され、ライブラリのJSON書き出しには含まれません。機種やブラウザを移行したあとはフォルダをもう一度選択してください） |
| localStorage | ライブラリ・パターン・編集CSV・音量と速度倍率の永続化 |
| Vanilla JS / HTML / CSS | フレームワーク不使用 |
